# silkreel CAD v0.1.0-cad.1

首个 Windows x64 预发布版本：读取真实 KiCad/STEP 模型，生成旋转展示、分层爆炸和制造装配影片，不推测器件外形。

下载 `silkreel-cad-0.1.0-cad.1-win-x64.zip`，解压后先阅读根目录 README，使用 Agent 辅助配置、审计、兼容性处理及逐帧验收。运行 `npm ci`，按 README 安装独立 Python 环境；需要 Node.js 22+、KiCad 10 和 Chrome/Edge。压缩包含预编译 CLI，非免依赖 EXE，不包含用户 PCB 和第三方器件模型。SHA256SUMS.txt 用于校验下载。

```powershell
npm run cad:setup -- --python "C:/path/to/python.exe"
npm run cad -- manufacture "board.kicad_pcb" --out exports/cad/film --azimuth=-45
```

本版完整验证范围为普通 4/6 铜层、明确叠层及贯穿孔。2 层、8 层及以上、盲埋孔/HDI、刚柔结合等需先适配并验收，发布入口不冒充支持。缺失模型、无效 CAD、未填充覆铜和不匹配装配会明确失败；已有 STEP 缺件默认失败，只有用户接受后才可使用有缺件标注的部分展示模式。

新增逐输出帧几何与裁切检查、完整视频逐帧解码和 PNG 保存、覆盖全片的接触表、章节静帧及首尾/乱序复位检查。必须配合 Agent/人工逐帧与全片视觉复核；自动报告不代表美观或制造准确性验收。

工艺动作、演示材质、锡膏显示厚度及回流光效为示意。实际几何和装配来自 CAD；不推测热场、设备轨迹、真实焊点或通孔焊接方法。

完整源码、兼容矩阵、检查清单和第三方许可随 tag 提供；更多命令见根目录 README 和 packages/cad/README.md。

## 本次发布验收

- 在全新解压目录执行 `npm ci`，并用独立 Python 虚拟环境安装固定版本 OpenCascade 与 Pillow；合成 STEP 渲染、4 铜层与 6 铜层制造影片均从发布包运行。
- 两种叠层的 48 秒测试片各 480 帧：逐帧几何/裁切报告均为 480/480、0 裁切；完整解码 480/480 帧，并用 10 fps 接触表覆盖全部帧后逐张检查。
- 章节静帧、首尾与乱序跳转复位、查看器正反面、PNG 下载、缓存隔离及完整视频播放通过。
- 未指定叠层、可见模型缺失、已有 STEP 缺件三条失败路径均按预期停止并保留失败状态。
- `tsc --noEmit`、`eslint packages/cad` 和需要原生 CAD 环境的 11 项 CAD 测试通过。
- 全仓库回归为 342 通过、15 失败；失败均为上游已有的 Windows 路径分隔符、测试中固定 macOS `/opt/homebrew/bin/ffmpeg` 路径及符号链接权限问题，不涉及本次 CAD 发布入口。该事实不标记为“全仓库全部通过”。

本次验收使用 KiCad 官方 3D 库中的 SOT-23、JST 连接器与合成测试板，不包含或分发用户 PCB、真实项目视频和第三方模型文件。
